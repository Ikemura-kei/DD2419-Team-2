# DD2419-Project-Course-in-Robotics-and-Autonomous-Systems  
**KTH Royal Institute of Technology | VT24 Robotics Project Course**  

🚀 **Project Overview**  
This repository hosts the code and documentation for the **DD2419 VT24 Project Course in Robotics and Autonomous Systems**, an advanced hands-on course focused on integrating robotics methods into a complete system. The project centers around developing a **mobile robot equipped with a robotic arm**, emphasizing practical implementation using ROS (Robot Operating System) and real hardware.  

🔧 **Key Components**  
- **ROS Integration**: Leverage ROS for modular system design, including perception, planning, and control.  
- **Mobile Manipulation**: Implement navigation, object detection, and arm control for dynamic tasks.  
- **Sensor Fusion**: Combine data from cameras, LiDAR, and IMUs for robust environment interaction.  
- **Simulation & Real-World Testing**: Validate algorithms in Gazebo and deploy on physical robots.  

📚 **Course Focus**  
- **Advanced Robotics**: Build on foundational knowledge (e.g., DD2410) to tackle real-world challenges.  
- **System Integration**: Bridge theory and practice by merging perception, decision-making, and actuation.  
- **Time Management**: Learn to prioritize tasks in a resource-constrained, hardware-driven environment.  

🛠️ **Technical Stack**  
- **Languages**: Python, C++  
- **Frameworks**: ROS, PyTorch (for perception tasks)  
- **Tools**: Gazebo, RViz, OpenCV, MoveIt!  
- **Hardware**: Mobile robot platform with a 6-DOF arm, depth cameras, and LiDAR.  

🎯 **Learning Outcomes**  
By contributing to this project, you will:  
1. Master ROS-based system design for robotics.  
2. Gain hands-on experience with sensor fusion and real-time control.  
3. Develop resilience in debugging hardware-software integration.  
4. Collaborate in teams to meet tight deadlines—a skill critical for industry roles.  

⚠️ **Prerequisites**  
- Strong foundation in ROS and robotics (e.g., DD2410 or equivalent).  
- Willingness to commit **240+ hours** (6 weeks full-time) to iterative development.  
- Comfort with Linux, Git, and command-line tools.
